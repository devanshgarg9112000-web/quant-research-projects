# Backtesting Framework

## Goal

This project builds a Python-based backtesting framework to test rule-based trading strategies using historical price data.

## Method

The strategy uses price data, moving averages, returns, shifted trading signals, and performance metrics to evaluate whether a trading rule performs better than a benchmark.

## Key Features

- Price return calculation
- Moving-average based signal generation
- Look-ahead bias prevention using shifted signals
- Strategy return calculation
- Equity curve generation
- Sharpe ratio
- Maximum drawdown
- Trade analytics
- Transaction cost adjustment
- Position sizing
- Monte Carlo testing
- Walk-forward validation

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Learning Outcome

This project helped me understand how trading strategies should be tested before trusting them, including risk metrics, drawdown, transaction costs, and train/test style validation.

## Note

This is an educational research project and should not be treated as investment advice or a production trading system.
