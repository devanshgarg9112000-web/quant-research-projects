# Benchmark Comparison

## Goal

This project compares a trading strategy against a simple buy-and-hold benchmark to check whether the strategy actually adds value.

## Method

The strategy equity curve is compared with the buy-and-hold equity curve. The project evaluates return, drawdown, and risk-adjusted behavior to understand whether the strategy performs better than simply holding the asset.

## Key Features

- Strategy equity curve
- Buy-and-hold equity curve
- Return comparison
- Maximum drawdown comparison
- Risk and performance evaluation
- Benchmark-based strategy validation

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Learning Outcome

This project helped me understand that a trading strategy should not only be profitable. It should also be compared against a benchmark to check whether it is actually useful.

## Note

This is an educational research project and should not be treated as investment advice or a production trading system.
