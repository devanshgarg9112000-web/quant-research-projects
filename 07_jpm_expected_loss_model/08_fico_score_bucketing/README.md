# FICO Score Bucketing

## Goal

This project creates a rating system by dividing FICO scores into buckets and assigning risk ratings.

## Method

The project uses borrower FICO scores and default information to create score buckets. Each bucket is analyzed using borrower count, defaults, and default rate. Higher FICO score buckets are treated as lower-risk ratings, while lower FICO score buckets are treated as higher-risk ratings.

## Key Features

- FICO score analysis
- Score bucketing
- Borrower count by bucket
- Default count by bucket
- Default rate calculation
- Credit rating assignment
- Borrower rating function

## Tools Used

- Python
- Pandas
- NumPy

## Learning Outcome

This project helped me understand how raw credit scores can be converted into practical risk buckets for credit-risk analysis.

## Note

This is an educational research project based on a virtual experience task and should not be treated as a production credit-risk model.
