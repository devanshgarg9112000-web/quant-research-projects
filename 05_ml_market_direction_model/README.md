# ML Market Direction Model

## Goal

This project builds a basic machine learning model to predict market direction using engineered quant features.

## Method

The project uses features such as momentum, volatility, moving-average ratios, distance from moving average, and lagged returns. A Logistic Regression model is trained to classify whether the next return is positive or negative.

## Key Features

- Quant feature dataset
- Train/test split
- Logistic Regression model
- Probability prediction
- Classification accuracy
- Confusion matrix
- Threshold-based signal generation
- Strategy equity curve comparison

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- scikit-learn

## Learning Outcome

This project helped me understand how machine learning can be applied to financial data, and why model evaluation, data leakage prevention, and realistic backtesting are important.

## Note

This is an educational research project and should not be treated as investment advice or a production trading system.
