# Quant Feature Engineering

## Goal

This project creates useful input features for a machine learning model using price and return data.

## Method

The project uses historical price data to create features such as momentum, volatility, moving-average ratios, distance from moving average, and lagged returns. These features are then used to prepare a dataset for market direction prediction.

## Key Features

- Return calculation
- Momentum features
- Rolling volatility features
- Moving-average features
- Moving-average ratio
- Distance from moving average
- Lagged return features
- Target variable creation
- Data preparation for machine learning

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Learning Outcome

This project helped me understand how raw price data can be converted into useful features for machine learning models, while also avoiding future data leakage.

## Note

This is an educational research project and should not be treated as investment advice or a production trading system.
