# Quant Research Projects

Python projects in quant research, backtesting, risk analytics, feature engineering, and machine learning.

## Projects

| Project | Focus |
|---|---|
| Backtesting Framework | Strategy returns, equity curve, Sharpe ratio, drawdown, trade analytics, transaction costs, position sizing, Monte Carlo testing, and walk-forward validation |
| Parameter Robustness Heatmap | Fast/Slow moving-average parameter testing and robustness analysis |
| Benchmark Comparison | Strategy vs buy-and-hold comparison |
| Quant Feature Engineering | Momentum, volatility, moving-average ratios, distance from moving average, and lagged return features |
| ML Market Direction Model | Logistic Regression model for market direction prediction |
| JPM Gas Price Estimation | Natural gas price interpolation and regression-based estimation |
| JPM Expected Loss Model | Probability of default and expected loss calculation |
| FICO Score Bucketing | FICO score risk buckets and rating assignment |

## Skills Used

Python, Pandas, NumPy, Matplotlib, scikit-learn, Backtesting, Risk Metrics, Feature Engineering, Logistic Regression, Linear Regression, Credit Risk Modeling

## Purpose

These projects were built as part of my preparation for Quant Analyst, Risk Analyst, Financial Data Analyst, and Quant Research Intern roles.
